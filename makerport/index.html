AI Delivery Robot: TeleMacc

Status: ONGOING...

Solving the "last mile" logistics crisis in rural Japan.

I am building an affordable, open-source AI delivery robot kit so that small local carriers can build their own autonomous infrastructure.

地方の輸送課題を解決するAIロボットの作り方を含めてオープンソース化する。

トラック運転手不足のため十数年前から宅配ロボは開発されてきた。しかし依然として地方の中小運送企業は苦しいままである。

そこで特に地方の中小運輸企業でも自作できるような廉価なキットを作成し、作り方も含めて無料でネット上に公開する。

電柱と白線に頼るテレフォンポールマッカートニープロトタイプを制作中である

Soccer Analysis

Status: FINISHED

Used YOLO to calculate the precise knee angle when touching the ball during juggling.

Provides data-driven feedback to help soccer players improve their technique and control.

YOLOを使用して、リフティング中にボールに触れる瞬間の正確な膝の角度を計算しました。

リフティング中に膝の角度を正確に知りたいと思うシチュエーションがあまりなかった。

Rongo Programming

Status: ONGOING...

Have you ever wondered why there is 論理 (Logic) programming but not 論語 (Rongo) programming?

Yes indeed, it is actually unfair, so I am making it. Shout-out to our fam 孔子 (Confucius).

I'm still reading "Crafting Interpreters," so it will be like year-long project.

「論理」プログラミングはあるのに、なぜ「論語」プログラミングはないのか？

これでは彼がかわいそうだと思ったので、私が作ることにしました。Shout-out to our fam 孔子

現在『Crafting Interpreters』を読んでいる最中なので、完成までは1年ほどかかる長期プロジェクトになりそうです。
